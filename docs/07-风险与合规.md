## 2. 合规红线（不可协商）

1. **不做资金池**：平台不经管资金、不设 wallet 余额，一切"支付"为意向记录。
2. **内容三重检查**：敏感词 → 版权素材 → 文化合规，出海内容过检才允许进发布参数包。
3. **AI 伦理**：学生交付必须附 AI 使用声明；教师端可比对 AI 初稿与终稿差异度，落实"AI 辅助而非替代"。
4. **个人信息**：企业侧看到的学生信息默认脱敏（隐藏姓名/联系方式）；建立联系需经学生同意。
5. **密钥管理**：密钥只进项目外 secrets 文件（`D:\VeriCall_data\secrets\opc_secrets.env`）与环境变量；推远端用 root-only 文件落盘，不回显。

## 3. 技术风险预案

| 场景 | 预案 |
|---|---|
| LLM 上游不可用 | 网关层重试 + 退避；连续失败返回 50002 并提示检查密钥；不做静默降级到本地模型 |
| DeepSeek 计费/限额变化 | 路由表可热切换到其他 OpenAI 兼容供应商（智谱/通义/火山） |
| SQLite→MySQL 迁移 | Alembic 迁移脚本同仓库；JSON TypeDecorator 屏蔽差异；上线前跑一遍迁移演练 |
| 存储从本地到 MinIO | Storage 抽象 + 键规范不变，切换驱动即可 |
