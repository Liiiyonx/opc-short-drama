# 01 · 项目范围与路线图

> V1.0 · 2026-10-16 · 依据《OPC短剧出海AI集合智能体平台开发文档》策划定稿

## 1. 产品全景

平台把短剧出海全链路封装为八大智能体，学生、教师、企业三端协同：

- 学生端："AI 剧本生成 → AI 分镜 → AI 配音 → 翻译本地化 → 成片合成 → 发布参数"全流程闭环
- 教师端：任务发布、Rubric 批改、能力图谱追踪、企业工单教学适配审核
- 企业端：真实工单发布、学生投标、成果遴选买单（意向制）、AI 人才匹配

## 2. P0-MVP 范围定义

### 2.1 做（且只做）

1. **学生端创作工坊**：向导式 5 步流水线（剧本 → 分镜 → 配音 → 字幕 → 成片），每步产物入库、支持单步重生成、多版本管理。
2. **四个智能体**：剧本、分镜、配音、翻译本地化，全部接入多模型网关与调用日志。
3. **教师端**：实训任务发布（绑定课程、组队规则、Rubric）、作品批改（分项打分 + 评语）、能力快照（五维，基于批改得分加权）。
4. **企业端**：工单发布（平台模板 + 指导价）、教师/管理员人工审核、工单大厅、学生团队投标。
5. **平台基础**：三端统一 JWT 登录、AI 使用声明（作品级）、异步任务队列（arq）、ffmpeg 成片合成、本地/MinIO 双存储驱动。
6. **部署**：docker compose 单机编排（nginx + api + worker + mysql + redis + minio），一键部署脚本。

### 2.2 不做（明确砍单，防范围蔓延）

| 砍单项 | 理由 | 替代方案 |
|---|---|---|
| 支付 / 结算 / 资金托管 | 高校主体无支付牌照，"平台托管赏金"= 变相资金池，合规红线 | 线上意向登记 + 线下结算，平台只存交易凭证 |
| 一键分发四平台 | TikTok/YouTube 官方 API 审核严、配额有限 | 生成发布参数包（标题/标签/时间），学生半手动发布 |
| 向量库 / RAG 检索 | 单 VPS 增负，MVP 无场景依赖 | 案例库先用关键词检索，P1 再评 Milvus Lite |
| Uni-app / 小程序 | 双端维护成本 ×2 | Vue3 响应式 Web 覆盖 PC + H5 |
| 企业工商实名 API | 对接成本与资质问题 | 人工审核营业执照 |
| 站内消息中心 | 非关键路径 | P1 用简单通知表实现 |
| 数据 / 优化 / 匹配智能体 | 依赖真实投放数据回流 | P1 随企业闭环一起上 |

## 3. 验收标准（Definition of Done）

1. 一名学生从登录到导出成片 MP4 全流程 ≤ 30 分钟（其中 AI 生成等待 ≤ 10 分钟，不含人工修改）。
2. 教师可发布任务 → 学生提交 → 教师 Rubric 批改 → 学生五维能力分发生变化，全链路跑通。
3. 企业可发布工单（经审核）→ 学生可见可投标，状态机正确流转。
4. 单 VPS `bash deploy.sh` 一键部署成功，演示数据（1 课程 + 1 任务 + 1 工单 + 2 学生）齐全。
5. 非 AI 生成类核心接口 P95 < 500ms；智能体调用 100% 落日志（token、耗时、成本估算）。
6. 所有 AI 产物可追溯到「哪个智能体、哪次调用、哪个模型、人工修改比例」。

## 4. 路线图

- **P0（第 1-8 周）MVP 闭环**：四智能体 + 三端最小可用 + 单机部署。出口条件 = 第 3 节验收标准全过。
- **P1（第 9-16 周）完整闭环**：八智能体齐、企业成果遴选买单（意向制）、嵌入 1 门课程试点运行。出口条件 = 试点课程一个完整教学周期 + ≥ 3 个企业工单走完"遴选-验收"。
- **P2（第 17-24 周）商业验证与复制**：真实工单跑通、学生团队入驻总工会 OPC 中心、一键部署脚本复制到同类院校。出口条件 = ≥ 1 笔真实订单收入 + 1 所外校部署意向。
