# 06 · 开发计划

> V1.0 · 2026-10-16 · P0-MVP 共 8 周，按周验收，不攒大招

| R2 后端 | 业务模块（任务/工单/能力） | |
| R3 前端负责人 | 学生端（创作工坊是最重 UI） | |
| R4 前端 | 教师端 + 企业端 | |

> 单人推进路径：按周顺序做，每周目标不变，第 5-7 周 UI 可降级为可用优先。

## 2. 八周排期

| 周 | 目标 | 交付物 | 验收标准 |
|---|---|---|---|
| W1 | 框架周 | 仓库/CI、docker compose（MySQL/Redis/MinIO）、FastAPI 骨架、DB 模型 + Alembic 首批迁移、JWT 登录、前端三端路由 + 登录页 | 三端可登录并落 token；`/health` 通；迁移可升可降 |
| W2 | 网关 + 剧本 | LLM 网关（client/router/quota/日志）、Agent 框架（base/registry/orchestrator）、剧本 Agent v1、作品模型 | 输入题材市场集数 → 出结构化分集大纲；调用日志可见 token 与成本 |
| W3 | 分镜 + 存储 | 分镜 Agent、Storage 抽象（Local/MinIO）、资产登记接口 | 剧本 → 分镜 JSON；上传/读取资产走统一存储 |
| W4 | 配音 + 成片 | Edge-TTS 封装 + 音色映射、SRT 生成、ffmpeg 合成、arq 异步任务 | 分镜 + 台词 → 配音 MP3 + SRT → 烧字幕 MP4；前端可轮询进度 |
| W5 | 学生端工坊 | 创作工坊向导 UI（5 步步骤条）、产物卡片、版本管理、AI 使用声明 | 学生跑通"登录→新建→五步→导出 MP4"≤ 30 分钟 |
| W6 | 教师端 | 任务发布（Rubric 配置）、提交列表、批改页、能力快照计算 | 教师发任务→学生提交→批改→学生能力分变化 |
| W7 | 企业端 + 订单 | 工单发布/审核、工单大厅、投标、订单状态机 | 企业发单（审核后）→ 学生投标 → 定标，状态流转正确 |
| W8 | 联调部署 | 生产 compose（nginx+api+worker）、deploy.sh、演示数据、冒烟测试、试点材料包 | 一键部署成功；第 3 节 DoD 全过；演示脚本走通 |

## 3. 里程碑

- **M1（W1 末）**：地基完工 —— 登录 + 数据库 + 部署骨架。
- **M2（W4 末）**：AI 流水线闭环 —— 剧本到成片，单人可用。
- **M3（W7 末）**：三端齐活 —— 教学闭环 + 工单闭环。
- **M4（W8 末）**：可部署可演示 —— P0 出口条件达成。

## 4. 协作规约

- 分支：`main` 保护 + `dev` 集成分支 + `feature/*` 功能分支；PR 合并前过 CI。
- 提交信息：`feat: / fix: / docs: / refactor: / test:`  Conventional Commits。
- 代码：ruff lint + 格式统一；后端单测覆盖核心服务层（P0 不追覆盖率，保主流程）。
- 节奏：每日 15 分钟站会（阻塞项优先）；每周五演示 + **更新 `docs/开发进度存档.md`**。
- 需求变更：进 `docs/01-范围与路线图.md` 的砍单表讨论，禁止口头加需求。

## 5. P1/P2 预告（不在本期）

P1（9-16 周）：八智能体齐（发布/数据/优化/匹配）、企业遴选买单（意向制）、AI 备课、1 门课程试点。
P2（17-24 周）：真实工单闭环、OPC 中心入驻、一键部署复制交付。
