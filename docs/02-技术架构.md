# 02 · 技术架构

> V1.0 · 2026-10-16

## 1. 技术选型（定稿）

| 层次 | 选型 | 理由 |
|---|---|---|
| 后端框架 | Python 3.11+ / FastAPI | 异步性能好，与 AI 生态衔接顺，自动生成 OpenAPI 文档 |
| ORM / 迁移 | SQLAlchemy 2.0（async）+ Alembic | 学生可读性高，迁移可回滚 |
| 数据校验 | Pydantic v2 | 与 FastAPI 一体，智能体输入输出契约直接用 |
| 任务队列 | arq + Redis | 比 Celery 轻，异步原生，单 VPS 无压力 |
| 数据库 | MySQL 8（生产）/ SQLite（开发） | 生产稳定；开发零配置，同一套模型 |
| 对象存储 | MinIO（生产）/ 本地磁盘（开发） | 统一 Storage 抽象，S3 兼容，自托管 |
| LLM 接入 | 自研多模型网关（OpenAI 兼容协议） | 默认云端 DeepSeek，可按智能体路由不同模型，成本配额可控 |
| TTS | Edge-TTS 起步，接口预留 CosyVoice/火山 | 零成本多语种；质量升级不换架构 |
| 媒体合成 | ffmpeg（服务端） | 图文动态短剧路线：分镜图 + 配音 + SRT → MP4 |
| 前端 | Vue 3 + Vite + Element Plus + Pinia + Vue Router | 生态成熟，学生维护成本低；响应式覆盖 H5 |
| 部署 | Docker Compose 单机编排 + Nginx | 单 VPS 4C8G 一键部署 |

**LLM 后端铁律**（沿用既有约定）：默认云端 DeepSeek（`LLM_BASE_URL` / `LLM_API_KEY` / `LLM_MODEL_DEFAULT`），密钥放项目外 secrets 文件；无密钥时明确报错并提示 source secrets，禁止静默回退本地 Ollama。

## 2. 总体分层

```
接入层    学生端(Web/H5) · 教师端(Web) · 企业端(Web) · 管理后台
          ↓ 同一 JWT 认证，按 role 分流
网关层    Nginx（反向代理 / 限流 / 静态资源）
          ↓
API 层    FastAPI /api/v1（REST + 统一包裹 {code,message,data}）
          ↓
业务层    教学管理 · 实训工作流 · 工单交易 · 能力图谱
          ↓
智能体中枢  Agent Orchestrator（注册表 / 流水线状态机 / 调用日志 / 配额）
          ├── 剧本 Agent · 分镜 Agent · 配音 Agent · 翻译 Agent（P0）
          └── 发布 · 数据 · 优化 · 匹配 Agent（P1）
          ↓
服务层    LLM 网关 · TTS · Storage · Media(ffmpeg) · Pipeline
          ↓
数据层    MySQL · Redis（队列/缓存） · MinIO（对象存储）
```

## 5. 智能体编排设计

- **Agent 基类**：每个智能体是独立类，声明 `name / input_schema / output_schema / is_async`，实现 `run(ctx)`。Pydantic 契约即文档，契约变更必须升版本。
- **注册表 + 编排器**：`orchestrator.invoke(agent_type, input, user)` 统一处理：参数校验 → 配额检查 → 调用执行 → 会话与产物落库 → 调用日志。新增智能体 = 加一个类 + 注册一行。
- **流水线状态机**（创作工坊）：`created → scripting → scripted → storyboarding → storyboarded → voicing → voiced → subtitled → composited → done`，任一步可单独重跑（生成新版本，`parent_id` 串版本链），失败可重试。
- **同步 / 异步**：LLM 文本类（剧本/分镜/翻译）同步返回；音视频类（配音/合成）走 arq 异步，返回 `task_id` 前端轮询（P1 升级 SSE）。

## 6. 多模型网关

```
services/llm/
├── client.py    # OpenAI 兼容 async 客户端（base_url/api_key 可配，超时/重试/退避）
├── router.py    # agent_type → (provider, model, temperature, max_tokens) 映射表
└── quota.py     # 每用户每日调用次数 / token 上限；每课程总量配额；超限返回 429
```

- 所有调用落 `agent_call_logs`：provider、model、prompt/completion tokens、耗时、成本估算（元）、状态。
- Prompt 模板放 `agents/prompts/`，版本化管理；教师端微调模板属 P1。
- 成本估算价格表内置（DeepSeek 计费），随模型切换更新。

## 7. 存储抽象

```python
class Storage(Protocol):
    def put(self, key: str, data: bytes, mime: str) -> str: ...
    def get_url(self, key: str, expire: int = 3600) -> str: ...
    def delete(self, key: str) -> None: ...
```

- 开发：`LocalStorage`（`./storage/`）；生产：`MinIOStorage`。键规范：`works/{work_id}/{kind}/{uuid}.{ext}`。
- 数据库只存键值，不存文件本体。

## 8. 部署形态

- **开发**：SQLite + 本地存储 + 可选 `docker-compose.yml` 起 MySQL/Redis/MinIO 做 parity。
- **生产**：单 VPS（4C8G + 200G SSD，Ubuntu 22.04）docker compose：nginx（前端 dist + 反代 /api）→ api → worker；mysql、redis、minio 同机；MySQL 每日全量 + binlog，MinIO 每日异地同步；容器健康检查 + 磁盘告警。
- 三端通过子域名分流（stu./tea./ent.），统一 JWT 认证。

## 9. 非功能需求

| 项 | 目标 |
|---|---|
| 性能 | 非 AI 接口 P95 < 500ms；列表分页 ≤ 100 条/页 |
| 并发 | 单 VPS 支持 50 并发用户；arq 并发 2（音视频合成 CPU 敏感） |
| 安全 | bcrypt 存密码；JWT 短时效 + refresh；全接口角色鉴权；上传文件类型白名单 |
| 可观测 | 结构化日志（请求 ID 贯穿）；智能体调用 100% 落库；/health 探活 |
| 备份 | MySQL 每日全量 + binlog；存储每日异地同步；备份保留 30 天 |
