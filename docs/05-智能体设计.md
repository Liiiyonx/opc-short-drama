# 05 · 智能体设计

> V1.0 · 2026-10-16 · **已实现 6 个**（剧本/分镜/翻译本地化/配音/成片合成/发布参数），P1/P2 契约先行定义

## 1. 智能体框架

```python
# agents/base.py 示意
class Agent(ABC):
    name: str                      # agent_type，唯一
    input_schema: type[BaseModel]  # Pydantic 输入契约
    output_schema: type[BaseModel] # Pydantic 输出契约
    is_async: bool = False         # 音视频类走 arq

    async def run(self, ctx: AgentContext) -> BaseModel: ...
```

- **注册表**：`registry.py` 中 `AGENTS = {"script": ScriptAgent, "storyboard": StoryboardAgent, ...}`。
- **编排器**：`orchestrator.invoke()` 统一做「契约校验 → 配额检查 → 执行 → 会话/产物落库 → 调用日志」。
- **模型路由**：`services/llm/router.py` 按 agent_type 返回 (provider, model, temperature, max_tokens)。

## 3. P0 智能体契约

### 3.1 剧本生成 Agent（script）

- 输入：`{genre, target_market, episodes, episode_minutes, style, keywords[], prev_outline?, feedback?}`
- 输出：`{title, logline, target_market, episodes: [{ep, title, outline, scenes: [{scene, location, characters[], dialogue[], note}]}]}`
- 多轮改写：带 `prev_outline + feedback` 增量重写，保留已确认集。
- System Prompt 草案（存 `agents/prompts/script_v1.md`）：

```text
你是资深短剧编剧，专精出海短剧（竖屏 9:16、单集 1-3 分钟、强钩子快节奏）。
基于用户给定的题材、目标市场、集数与单集时长，产出结构化剧本。要求：
1. 每集前 3 秒必须有强钩子（冲突 / 悬念 / 反转 / 视觉冲击）；
2. 对话简短口语化，单句不超过 20 字，适配目标市场文化，避开文化禁忌；
3. 严格遵守用户指定的 JSON 结构输出，不要输出任何额外解释。
```

### 3.2 分镜 Agent（storyboard）

- 输入：`{episode_script, aspect_ratio="9:16", style_hint?}`
- 输出：`{shots: [{shot_no, scene, shot_size, camera_move, visual_prompt, dialogue, duration_sec}]}`
- `visual_prompt` 用英文，供 AI 绘图 / 素材检索；含主体、动作、环境、光线、风格。
- System Prompt 草案：

```text
你是专业分镜师，擅长竖屏短剧分镜。将给定剧集拆解为镜头列表。
每个镜头必须包含：镜号、所属场景、景别（特写/近景/中景/全景）、运镜（推/拉/摇/移/固定）、
画面提示词（英文，包含主体、动作、环境、光线、风格）、对应台词、时长估算（秒，总时长需匹配单集时长）。
只输出 JSON，不要额外解释。
```

### 3.3 配音 Agent（tts）

- 输入：`{lines: [{line_id, role, text, lang}], voice_map?}`
- 输出：`{assets: [{line_id, audio_key, duration_ms}], merged_audio_key?, srt_key}`
- 音色映射（Edge-TTS 默认表，可在配置覆盖）：
  | 角色类型 | 中文 | 英文 |
  |---|---|---|
  | 旁白 | zh-CN-XiaoxiaoNeural | en-US-AriaNeural |
  | 男主 | zh-CN-YunxiNeural | en-US-GuyNeural |
  | 女主 | zh-CN-XiaohanNeural | en-US-JennyNeural |
- 字幕：按台词时间轴生成 SRT，支持人工校轴后重烧。
- 异步执行（arq），进度 0-100 可轮询。

### 3.4 翻译本地化 Agent（translate）

- **实现状态（2026-10-16）：已实现**。契约由单文本升级为**台词批量**（保上下文连贯、省调用），
  容错两层：模型回显输入结构时自动归一化（text→translated）、漏行以原文兜底。
- 输入：`{lines: [{line_id, text, role?}], source_lang?, target_locale}`
- 输出：`{lines: [{line_id, translated}], notes[], compliance_flags[{line_id?, issue, suggestion, severity}], target_locale}`
- 由商务英语专业主导：跨文化改写（文化等价替换）、俚语适配、敏感词与文化禁忌标记；
  合规扫描覆盖：宗教禁忌 / 政治敏感 / 社会歧视 / 未成年人 / 平台红线。
- 落库：作品类型 `translate`（工坊第 3 步，可选）；中间产物 JSON + 元数据（行数/替换说明数/合规标记数）。
- System Prompt 见 `backend/app/agents/prompts/translate_v1.md`（含输入输出对照示例）。

## 5. 工坊流水线状态机

```
created → scripting → scripted → storyboarding → storyboarded
       → voicing → voiced → subtitled → composited → done
```

- 每步绑定一个智能体；任一步可单独重跑，产物生成新版本（parent_id 串链）。
- `failed` 状态可重试；重试保留历史调用日志。
- 每步产物自动落 `work_assets`；成片步骤 ffmpeg 合成（分镜图 + 配音 + SRT 烧录 → MP4，libx264 + faststart）。

## 6. Prompt 资产管理

- Prompt 模板存 `backend/app/agents/prompts/{agent}_v{n}.md`，与代码同仓库版本化管理。
- 每次调用记录使用的 prompt 版本（入 `agent_sessions.meta_json`），保证结果可复现。
- P1：教师端可按课程微调模板并另存版本。

## 7. 配额与成本

- 每用户每日：文本类智能体 ≤ 50 次；异步媒体类 ≤ 10 次。
- 每课程每周总量配额（防一个班刷爆）。
- 超限 → 42901 + 日志。成本估算按内置价格表（DeepSeek 计费）计算，落 `agent_call_logs.cost_est`。
