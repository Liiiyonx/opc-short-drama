# 演示脚本 · 15 分钟全链路

> 配套本项目 P0-MVP：三端（学生 / 教师 / 企业）+ 四智能体（剧本 / 分镜 / 配音 / 合成）。
> 目标：15 分钟内跑完「创作 → 教学 → 产业」完整闭环（对应 docs/01 验收标准）。

## 0. 演示前准备（5 分钟，不计入）

```bash
# 终端 1：后端
cd backend && python -m uvicorn app.main:app --port 8000

# 终端 2：异步 worker（配音/成片合成）
cd backend && python -m arq app.workers.tasks.WorkerSettings

# 终端 3：前端
cd frontend && npm run dev

# 首次或重置：迁移 + 演示数据
cd backend && python -m alembic upgrade head && python -m scripts.seed
```

浏览器开两个窗口（或随时切账号），登录页 `http://localhost:5173`。

| 角色 | 账号 | 口令 | 用途 |
|---|---|---|---|
| 学生 | student01 | student123 | 创作工坊 + 技能提交 + 投标 |
| 教师 | teacher01 | teacher123 | 发布任务 + Rubric 批改 + 工单审核 |
| 企业 | enterprise01 | ent123456 | 工单发布 + 定标 |

> 备注：服务器未配置 DeepSeek 密钥时用 `LLM_PROVIDER=mock TTS_PROVIDER=mock` 启动后端，
> 全流程可跑通（产物为桩数据）；配好密钥即为真实 AI 生成。

## 1. 开场（1 分钟）

一句话定位：**把短剧出海全链路（剧本→分镜→配音→字幕→成片）封装为 AI 流水线，
把高校课堂、学生能力成长、企业真实需求串成一体的产教融合平台。**

## 2. 学生端 · 创作工坊（5 分钟）

1. 登录 `student01` → 工作台展示统计卡片、我的任务、我的能力。
2. 点「新建剧集」→ 输入剧名 → 进入创作工坊（五步步骤条）。
3. **第 1 步 剧本**：题材选「逆袭」、市场「北美」、2 集 × 2 分钟 → 生成剧本
   → 展示分集大纲与结构化产物卡片（JSON 可下载）。
4. **第 2 步 分镜**：创建分镜作品 → 选第 1 集 → 生成 → 镜头表格（景别/运镜/英文画面提示词，一键复制）。
5. **第 3 步 配音**：创建配音作品 → 生成 → **展示异步轮询进度**（arq worker 执行）→ 音频播放器 + SRT 卡片。
6. **第 4 步 字幕**：生成 SRT（可下载校轴）。
7. **第 5 步 成片**：创建成片作品 → 合成 → **播放 MP4**（图文动态短剧：图片序列 + 配音 + 烧字幕）
   → 填写并保存 **AI 使用声明**（用了哪些智能体、人工修改比例）。

> 讲点：每步产物入库（版本链）、任一步可单独重跑、成本与 token 全部落 `agent_call_logs`。

## 3. 教学闭环（4 分钟）

8. 学生工作台「我的任务」→ 点「提交作品」→ 勾选刚完成的成片 → 提交。
9. 切换 `teacher01` 登录 → 教师工作台：
   - 「发布任务」：展示 Rubric 编辑器（评分项 / 五维能力维度 / 权重自动归一化 / 达标分）。
   - 进入示范任务的「提交列表」→ 展开学生提交 → 点「批改此作品」。
10. **批改抽屉**：产品预览（视频/字幕/JSON）+ AI 使用声明 + 五维分项打分（滑块）+ 评语 → 提交
    → **加权总分与达标判定实时计算**。
11. 再切回 `student01` → 工作台「我的能力」五维进度条已更新（能力快照事件溯源）。

> 讲点：批改触发 `ability_snapshots` 只追加记录，任意时刻可回溯成长曲线；
> 教师只读查看学生作品，写操作严格限本人。

## 4. 企业端 · 工单闭环（4 分钟）

12. 切换 `enterprise01` → 企业工作台点「发布工单」：
    题材/市场/集数/预算（3000 元）/交付要求 → 提交审核（状态：待审核）。
13. 切换 `teacher01` → 工作台顶部「待审核工单」→ 通过（合规审核：营业执照 + 需求清晰度）。
14. 切换 `student01` → 「工单大厅」→ 看到工单 → 投标（报价 + 方案）
    → 能力门槛校验：五维均分 ≥ 60 才可投标（不足会明确提示）。
15. 切换 `enterprise01` → 工单详情 → 查看投标列表 → **定标** →
    状态流转：`已发布 → 投标中 → 已定标`，大厅自动下架。

> 合规说明：P0 不做支付托管，平台只存交易凭证，线下结算。

## 5. 收尾（1 分钟）

- **技术底**：FastAPI + SQLAlchemy 异步 + arq/Redis + ffmpeg + Vue3/Element Plus，
  LLM 网关（DeepSeek 云端 + 成本估算 + 配额），LLM/TTS 皆有显式测试桩（无密钥不静默降级）。
- **部署**：`bash deploy.sh` 一键拉起（nginx + api + worker + mysql + redis + minio）。
- **数据**：14 张表、真实迁移链（alembic）、成本/调用日志可查。

## 常见问题速查

| 现象 | 处理 |
|---|---|
| 生成接口报「未配置 LLM_API_KEY」 | 按提示配置密钥，或 `LLM_PROVIDER=mock` 演示 |
| 配音/成片一直"生成中" | 检查 worker 终端是否在跑（arq）；超 30 分钟系统会自动判失败并提示，作品回落可重试 |
| 前端提示「等待超时 / 处理时间较长」 | 确认 worker 与 Redis 在跑；恢复后点「刷新状态」或重试生成 |
| LLM 偶发返回非法 JSON | 系统自动发起修复重试（无需人工干预）；连续失败看 `agent_call_logs.error` |
| 端口被占用 | 后端 `--port`、前端 `npm run dev -- --port 5199`、代理目标 `VITE_API_TARGET` |
| 演示数据重复 | `python -m scripts.seed` 幂等，不会重复插入 |
