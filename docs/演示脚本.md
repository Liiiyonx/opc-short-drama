# 演示脚本 · 15 分钟全链路

> 配套当前版本：三端（学生 / 教师 / 企业）+ 管理后台 + **十智能体**（创作六步 + 数据分析 + 优化建议 + 人才匹配 + AI 备课）。
> 目标：跑通「创作 → 教学 → 产业 → 数据闭环」完整故事（对应 docs/01 验收标准）。

## 0. 演示前准备（5 分钟，不计入）

```bash
bash demo_up.sh          # 真实 AI 模式（自动加载项目外密钥）
# 或 bash demo_up.sh --mock   # 无密钥离线演示（显式测试桩）
# → 浏览器打开 http://127.0.0.1:5199
```

浏览器开两个窗口（或随时切账号）。

| 角色 | 账号 | 口令 | 用途 |
|---|---|---|---|
| 学生 | student01 | student123 | 创作工坊 + 技能提交 + 投标 |
| 教师 | teacher01 | teacher123 | 备课/任务 + Rubric 批改 + 工单审核 |
| 企业 | enterprise01 | ent123456 | 工单发布 + 人才匹配 + 定标 |

> 登录页支持**演示账号一键填充**（点角色卡即填好账密）。可顺手点顶栏月亮切暗色模式展示。

## 1. 开场（1 分钟）

一句话定位：**把短剧出海全链路封装为 10 个智能体（创作六步 + 数据复盘 + 优化建议 + 人才匹配 + AI 备课），
把高校课堂、学生能力成长、企业真实需求串成一体的产教融合平台。**

## 2. 学生端 · 创作工坊（4 分钟）

1. 登录 `student01` → 工作台：统计卡 / 我的任务 / 五维能力。
2. 点「新建剧集」（或进入已有剧集）→ 创作工坊，**步骤导航**：五态节点（完成✓/生成中/当前/待处理/未解锁）+ 总进度条。
3. **第 1 步 剧本**：题材「逆袭」、市场「北美」→ 生成（真实 DeepSeek ~15s）
   → 展示分集大纲 + **成本芯片**（tokens · ¥ 成本 · 耗时）+ 集数折叠卡（场景/角色/台词）。
4. **第 2 步 分镜** → 镜头卡片按场景分组（镜号徽章 / 景别运镜标签 / 台词气泡 / 画面提示词一键复制）→ 点「复制全部提示词」（对接文生图）。
5. **第 3-4 步 配音**（异步 worker，Edge-TTS 多语种）+ **第 5 步 字幕**（SRT 校轴 + 差异度比对）。
6. **第 6 步 成片** → MP4 播放（烧字幕）→ **发布参数包**（TikTok/YouTube/ReelShort 三平台文案+标签+时间建议）
   → **数据复盘**：回填播放数据 → 复盘报告（互动率计算/归因）→ **优化建议**（优先级排序 + 下一部剧选题）。
7. 顶部「**运行记录**」抽屉：本剧集全部智能体调用（状态/输入/输出 JSON 可展开）——成本与过程全留痕。

> 讲点：每步产物入库（版本链）、任一步可单步重跑、成片有历史版本预览墙、
> 每次调用成本/token 全程可见（对应"AI 辅助而非替代"与单位经济模型）。

## 3. 教学闭环（3 分钟）

8. 学生把成片提交到实训任务 → 切 `teacher01`：
   - 「AI 备课」：输入课程+主题 → 教案草案（目标/环节/讨论题/实训/Rubric 建议）→ 复制全文。
   - 「发布任务」：Rubric 编辑器（评分项/五维维度/权重归一化/达标分）。
   - 待批改作品 → **批改抽屉**：产物预览 + AI 声明 + 分项打分 + 实测修改度 → 提交。
9. 切回 `student01` → 五维能力已更新（能力快照事件溯源）；
   「学习档案」→ 打印视图（可导出 PDF）；「分享作品集」→ 脱敏链接（免登录可见）。

## 4. 企业端 · 工单闭环（3 分钟）

10. 切 `enterprise01` → 发布工单（提交审核）→ 切 `teacher01` 审核通过。
11. 切 `student01` → 工单大厅投标（能力门槛 ≥60 校验）→ 切回企业 →
    工单详情：投标列表 → **AI 人才匹配**（脱敏排行 + 侧重维度打分）→ **定标**。
12. 状态机流转：`已发布 → 投标中 → 已定标`，大厅自动下架。

## 5. 数据与收尾（4 分钟）

13. 切 `teacher01` → **AI 用量看板**：总调用 / tokens / 成本、按智能体分布、每日趋势、用户 Top——
    现场报出"本班累计成本 ¥X"（对应单位经济模型 0.017 元/链路）。
14. **能力预警**卡：低分学生红底高亮 + 薄弱维度 + 辅导建议。
15. 收尾话术：技术底（FastAPI 异步 + arq + ffmpeg + Vue3）、55+ 测试用例、CI、
    一键部署 + 每日备份、成本透明可审计、暗色模式适配。路线图：半自动发布 / 编排画布。

## 常见问题速查

| 现象 | 处理 |
|---|---|
| 生成接口报「未配置 LLM_API_KEY」 | 按提示配置密钥，或 `LLM_PROVIDER=mock` 演示 |
| 配音/成片一直"生成中" | 检查 worker 终端是否在跑（arq）；超 30 分钟系统自动判失败并提示，作品回落可重试 |
| 前端提示「等待超时 / 处理时间较长」 | 确认 worker 与 Redis 在跑；恢复后点「刷新状态」或重试生成 |
| 报「今日配额已用完」 | 媒体类默认 10 次/天，彩排会撞——用 `bash demo_up.sh`（默认放宽到 100）或调 `QUOTA_MEDIA_CALLS_PER_USER_DAY` |
| Edge-TTS 报 403 / 无法连接 | 网络无法访问微软语音服务：检查网络/代理；或改 `TTS_PROVIDER=mock`；`python -m scripts.selfcheck` 一键定位 |
| LLM 偶发返回非法 JSON | 系统自动发起修复重试（无需人工干预）；连续失败看 `agent_call_logs.error` |
| 端口被占用 | 后端 `--port`、前端 `npm run dev -- --port 5199`、代理目标 `VITE_API_TARGET` |
| 演示数据重复 | `python -m scripts.seed` 幂等，不会重复插入 |
| 演示前全面体检 | `cd backend && python -m scripts.selfcheck`（含真实 LLM 与 Edge-TTS 调用） |
| 登录连续失败被锁 | 防爆破机制：失败 10 次锁 5 分钟；演示用一键填充不会触发 |
